How the measurement works

Four phases, zero guesswork.

01

Latency & jitter

Small GET probes timed with performance.now(). Jitter is the mean delta between consecutive round trips.

02

Streamed download

Parallel binary streams consumed through ReadableStream and response.body.getReader(), counting raw octets.

03

Verified upload

Incompressible blobs from crypto.getRandomValues() are POSTed in parallel, tracked via xhr.upload.onprogress.

04

Honest scoring

The first 1.5 seconds of every stream is discarded so TCP slow-start cannot skew the result. Every request uses a unique ?t= cache-buster.

Configuration

Test server

This page is a single self-contained file. By default it measures against Cloudflare's public speed-test endpoints (CORS-enabled). To test against your own server, set BASE_URL to a server that implements GET /ping, GET /download?bytes= and POST /upload with CORS enabled.
